Backend Authentication System – Coding Assignment
Design and implement a secure and scalable authentication system using Node.js, Express.js, TypeScript, Sequelize/Prisma, JWT, and Redis.
Requirements
User registration and login with secure password hashing.
JWT-based authentication and authorization.
Allow only one active device/session per user.
Support logout from the current device and login from a new device.
Use Redis for session, token, and device management.
Implement file upload using Multer.
Use a queue system such as BullMQ/RabbitMQ + Redis for background email tasks.
Implement input validation and centralized error handling.
Securely manage authentication tokens, sessions, and sensitive data.
Use Sequelize or Prisma for database operations.
Follow a clean, scalable, and modular project structure.
